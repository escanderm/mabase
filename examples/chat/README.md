# Пример-чат: как появился API

Рабочий чат теперь лежит в [`chat/`](../../chat) в корне репозитория:
конфиг, хуки, сид и фронтенд. Его запускает `mabase serve`.

Здесь осталось то, с чего он начинался на шаге 3 (`design.md` §19):

```
API-NOTES.md      что всплыло при написании - 12 вопросов к API и находки шагов 7b-8
client/chat.ts    набросок клиента на SDK - каким задумывался API
```

**Начинать с `API-NOTES.md`**: там то, ради чего пример писался.
