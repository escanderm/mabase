# Чат на MaBase

Рабочий проект на MaBase: чат с закрытыми комнатами. Так выглядит
приложение пользователя: рядом лежат бинарник, конфиг, хуки и фронтенд, а
`mb_data/` создаётся сам. Это релиз v0.1 (`design.md` §19, шаг 9).

## Запустить

```bash
cd core && bun run build && cd ../chat   # собрать бинарник: core/dist/mabase
../core/dist/mabase seed                 # 3 пользователя, 2 комнаты, 5000 сообщений
../core/dist/mabase serve --dev          # http://localhost:8090
```

Без сборки, из исходников: `bun ../core/src/cli.ts seed` и `bun ../core/src/cli.ts serve --dev`.

Открыть http://localhost:8090 и войти как `alice@example.test` / `dev-alice-1`.
Второго пользователя (`bob@example.test` / `dev-bob-1`) - в другом браузере
или по адресу http://127.0.0.1:8090: у разных адресов разное хранилище, и
сессии не смешаются.

## Что умеет

- вход и регистрация (имя обязательно - так расширена встроенная `users`);
- комнаты: создать, переименовать (владелец), выйти, удалить со всеми
  сообщениями (владелец);
- пригласить по email (приглашённому уходит письмо; без настроенной почты -
  в консоль сервера), принять приглашение, выгнать участника;
- сообщения: последние 50, подгрузка старых при прокрутке вверх, правка и
  удаление своих;
- "печатает..." - только участникам комнаты;
- кто в сети - только из своих контактов;
- выгнали или удалили комнату - она закрывается сама;
- после обрыва связи и рестарта сервера всё догоняется само.

## Что здесь показывает MaBase

| Что | Где |
|---|---|
| Правила-фильтры: видно только свои комнаты и их сообщения | `mabase.config.ts`, `rules` |
| `dependsOn`: выгнали из комнаты - лента и "в сети" перечитываются | `messages`, `users`, `_presence` |
| Бизнес-логика - действия-транзакции | `createRoom`, `invite`, `acceptInvite`, `leaveRoom`, `kick`, `deleteRoom` |
| Поля `readonly`, `immutable`, `private` | `fields` |
| Клиентское событие с `allow` и `to` | `events.typing` |
| Отложенное событие в той же транзакции, письмо через `mail.send` | `invite` + `mb_hooks/invite-email.ts` |
| Живые выборки, окно и подгрузка через индекс | `mb_public/app.js` |
| Идемпотентный сид пачками | `seed.ts` |

## Файлы

```
mabase.config.ts          коллекции, правила, действия, события
mb_hooks/invite-email.ts  письмо о приглашении (отложенное событие, mail.send)
seed.ts                   тестовые данные
mb_public/                фронтенд: index.html, app.js, style.css
mb_data/                  база - создаётся сама, в git не идёт
```

Фронтенд берёт SDK прямо с сервера: `import { createClient } from
'/api/client.js'`. Ни npm, ни сборщика.

Как появился этот API и какие вопросы всплыли по дороге - в
`examples/chat/API-NOTES.md`.
